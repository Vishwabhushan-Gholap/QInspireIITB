# QInspireIITB

Data and plotting code for the figures in:

**Quantum-Inspired Tensor Networks: Efficient Pauli Decomposition and Multistage Refinement for Sturm–Liouville Eigensolvers**
V. S. Gholap, H. S. Dhar and S. Santra, *submitted to Quantum Science and Technology* (2026).

## Contents

| Folder | Figures |
|---|---|
| `II_C_Pauli_decomposition` | Fig. 3 |
| `III_A_Diffusion_Equation` | Figs. 4, 5 |
| `III_B_2D_Anharmonic_Oscillator` | Figs. 6, 7 |
| `III_C_Random_potential_in_one_dimension` | Figs. 8, 9 |
| `III_D_Error_in_MPOs` | Fig. 10 |

Each folder contains the data (`.xlsx`, `.csv`, `.jld2`) and the notebooks (`.ipynb`) used to produce the figures.
